# v0.4.10 连接与界面修复

## VPN / Clash 兼容控制器

1. 在客户端启用 External Controller，绑定本机地址，例如 `127.0.0.1:9090`。
   这是控制接口；UniClash 的 `8993` 或 Clash 的 `7890` 等混合端口用于代理流量。
2. 灵动岛插件设置填写完整控制地址及客户端配置的 Secret。诊断只读取
   `/proxies` 和 `/configs`，不会更改节点或模式。
3. 选择包含实际节点的手动策略组。默认展示五个最快节点并保留当前节点。
   测速基于核心的节点延迟 API，并非下载带宽测试。
4. 默认每轮完成后等待 60 秒再次测速，设置可调 15–3600 秒；单节点超时
   默认 4000 毫秒，可调 1000–15000 毫秒。最多四个并发请求，同一时间仅一轮。
   切换页面继续监控；禁用/卸载插件停止下一轮，旧请求的结果不会更新新配置。
5. 点击节点名称执行真正切换，模式按钮也写入核心，再回读确认。失败保留原状态，
   显示超时、密钥错误或控制器不可用信息。
6. 在列表勾选候选节点，或在设置中以逗号分隔填写完整名称，再启用自动切换。
   仅当前节点本轮失败、候选节点本轮可用时，选择延迟最低的指定候选。
   不会为了更低延迟切换正常节点，直连模式不触发。切换前重新检查状态，
   不覆盖用户在客户端刚做的手动切换；全部候选不可用时保留当前选择并提示。

测速与自动切换由运行中的灵动岛监控。退出灵动岛后不会继续运行。
在规则模式中，节点切换只作用于所选策略组，具体网站仍由客户端规则决定。
全局模式使用 `GLOBAL` 组。

实现遵循 [Mihomo 控制 API](https://wiki.metacubex.one/api/)。只允许本机控制地址，
不跟随重定向，不提供任意 HTTP 代理。没有增加依赖、后台服务或流量图表库。

## Obsidian

设置保留仓库绝对路径、日记相对目录及命名格式，默认 `YYYY-MM-DD`。
支持 `YYYY年MM月DD日`、`YYYY/MM/DD` 等年/月/日组合，按本地日期命名，
拒绝绝对文件名、路径穿越及非法字符。原有日记目录和旧名称配置仍可读取。
最近笔记共用 Everything 插件端口，索引失败明确显示错误，空索引不冒充连接失败。
诊断只读取索引并预览文件名，不打开或创建笔记。

## AI 智能体

- 同步原作者 `b54a6e8`：空闲图标使用最近有会话的智能体，修复只使用 Codex
  却显示 Claude 的问题。
- 移除上方 ChatGPT 标签。Antigravity 通过运行中应用的本机语言服务读取
  `RetrieveUserQuotaSummary`，每分钟刷新真实的 5 小时/每周模型分组额度。
  本机服务 CSRF 只在后台内存中使用，不发布给前端，也不读取 Google 登录凭据。
  进程或端口变化时重新发现；客户端关闭、未登录或接口不可用时显示明确错误。
  本机接口可能随 Antigravity 升级变化；当前仅接入额度，不推算 Token 或会话状态。
- Antigravity 按实际安装路径启动。输入操作说明为“复制并打开”，用户到客户端
  粘贴；复制或启动失败保留输入，避免报告已经发送。

## 布局及图标

共用按钮保留单行文字并禁止被 Flex 挤窄；AI 输入框使用可收缩的剩余宽度。
展开区保留内容的最小高度，空间不足时滚动；工具栏不再抢占文字高度。
NavoPath 使用原始透明 PNG 的 96 px 缩小版，保留原形状、白色正面和黑色侧面，
约 3.5 kB；没有使用形状不同的 SVG。
